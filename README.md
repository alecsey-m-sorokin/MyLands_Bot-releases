# MyLands Bot — сборки

Здесь только сборки программы для автообновления (раздел **Releases**).
Исходного кода здесь нет.

- Новую версию программа находит и предлагает установить сама: кнопка «⬆ Обновления» в окне «Аккаунты».
- Каждый выпуск подписан. Программа проверяет подпись и контрольную сумму архива перед установкой.
- Для работы нужен ключ лицензии.
